Inventario del Almacen

Aplicacion web para registrar productos de un almacen, hecha con React,
Vite y Firebase Firestore.

Como instalarlo:
1. Ejecutar npm install
2. Copiar el archivo .env.example y renombrarlo a .env
3. Completar .env con los datos de un proyecto de Firebase
4. Ejecutar npm run dev
5. Abrir la direccion que aparece en la terminal

Que hace la aplicacion:
Permite agregar productos con su nombre, cantidad y precio, editarlos o
eliminarlos, y muestra un resumen con el total de productos, las unidades
en stock y el valor total del inventario.
